# Const.Elate

A terminal character sheet and skill tree for Claude Code, in the style of an RPG
constellation tree.

It is a visual editor over the plain files Claude Code already reads: the skills under
`~/.claude/skills`, your `CLAUDE.md`, the permissions in `settings.json`, and the session
transcripts. It never runs an agent of its own. If you uninstall it, your Claude Code setup keeps
working unchanged.

## What you get

- **A constellation** of your skills, sorted into Coding, Writing, Research, Ops, Design and
  your own categories, with what each one costs in always-loaded context.
- **A character sheet**: the agent's name, the model, and a CLAUDE.md editor for the user and
  project files.
- **A ledger** of XP per session, and trust unlocks that suggest an allow rule once a command
  has earned it.
