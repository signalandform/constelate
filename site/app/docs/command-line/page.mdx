# Command line

Without flags, `constelate` opens the TUI with the current directory as the project. These flags
change that.

| Flag | Does |
|---|---|
| `--summary` | Print a read-only report and exit: skills by scope, context cost against budget, character sheet sources, trust progress, XP totals |
| `--summary --json` | The same report as JSON, for scripts |
| `--dry-run` | Open the TUI, but describe every write instead of making it |
| `--render WxH[+key...]` | Draw one frame at that size, press the given keys, print it and exit |

## Render

`--render` needs no TTY, so it works in scripts, CI and screenshots. Keys after the size are
pressed in order before the frame is captured:

```sh
constelate --render 80x24                # the constellation, as first drawn
constelate --render 96x30+tab+enter      # next constellation, detail panel open
constelate --render 96x30+2              # the character sheet
constelate --render 96x30+3              # the ledger
```

Key names are the ones the TUI uses: `tab`, `shift+tab`, `enter`, `esc`, `up`, `down`, `left`,
`right`, and single characters. Every frame on this site was made this way.

## Exit codes

`0` on success. `1` with a message on stderr when a flag is malformed or a required directory
cannot be read. The TUI leaves the terminal as it found it on <kbd>q</kbd> or <kbd>ctrl+c</kbd>.
